# Quinta Vista Hermosa

Landing page de Quinta Vista Hermosa · Suites & Eventos (Santiago, Nuevo León).

Sitio estático: `index.html`, `styles.css`, `main.js` y `assets/`. No requiere build.

## Desarrollo local

```bash
python3 -m http.server 5173
```

Abrir http://localhost:5173

## Contenido

- Fotos en `assets/img/` (agregar más desde la página de Facebook).
- Lugares cercanos: arreglo `ATTRACTIONS` en `main.js`, imágenes en `assets/img/alrededores/`.
- Normas de hospedaje: sección `#normas` en `index.html`.
